4. System calls around each read benchmark (counting probe, 1,000,000 keys; one run of each read benchmark)
------------------------------------------------------------
Each probe run opens a clone of the shale first-pass database as it is (PROBE_EXISTING=overwrite), waits for the
background, and runs the four reads once each, with the counting library loaded (pread, read, write, mmap, munmap, fsync,
fcntl(F_FULLFSYNC)). A SNAP line counts the calls since the SNAP line before it; "loop start X" covers what came before the
first run of X (in the compacted state, the compaction), and "after 1 x X" the run of X. The probe prints the engine's
state after each step. "Compacted" is PROBE_COMPACT=1: the probe compacts the whole range before the first read and waits
for the background. The builds are v011 (v0.1.1) and final (0.1.2); the command line of each run is in section 0.

6. The first session of 2026-11-22, superseded
------------------------------------------------------------
What it was. The first measured session ran on 2026-11-22, its first run starting at 18:50:45 and its last ending at
21:14:36, under sections 1 to 8 of the protocol as first committed (59e795e): 67 runs of shale_bench (A 10, B 30, W 15,
C 12) and 16 probe runs, and 4 more probe runs on E and E+F that the protocol did not list. Every run exited with status 0
and none was run again. Each build's shale_bench was compiled from that build's own tree; each full command wrote a
database and then read it; the writes were timed until the last write returned, and the engine's counters were read then.
Its JSON files, its evidence file and its documents are at commit 3270703 (pull request #27, which was not merged). It is
not a result. Its first-pass figures are not comparable with this session's (protocol, section 9.6), and none of its
figures is quoted as a measurement of 0.1.2 in docs/benchmarks.md.

What it showed (0.1.2 / v0.1.1, the median of three rounds; the rule of section 6 of the protocol):
  reads, first pass:   readrandom 0.94, readmissing 0.83, seekrandom 0.59 (each "moved", slower); readseq 1.32 (moved)
  reads, compacted:    readrandom 1.01 (not distinguishable), readmissing 1.13, readseq 1.94, seekrandom 1.23 (moved)
  writes, in rounds:   fillseq 0.88, fillrandom 0.82, overwrite 0.72 (each "moved", slower)
  0.1.2 / LevelDB, first pass and compacted: readrandom 0.70 and 0.77, readmissing 1.16 and 3.07, readseq 0.45 and 0.87,
  seekrandom 0.26 and 0.84; writes 0.92, 0.95 and 0.75.

The cause. An investigation that evening (22:00 to 22:25), outside the protocol, with its experiments run under a 1-minute
load of 1.8 to 3.0 (another agent's test suite had just finished); none of its experiments is a result of the protocol. Its
scratch files and logs stay, untouched, in the first session's scratch directory, of which this session's $WORK is the
subdirectory r2. It found:
  - E makes compaction faster. Compaction reads every input table through Table::NewIterator()
    (src/db/compaction_job.cc), the iterator E rewrote, so the wrappers and the key copy at each step that E removed were
    on the compaction path too.
  - At 1,000,000 keys that decides whether the one background thread keeps up with overwrite. E's does: every L0->L1
    compaction takes 4 files, 50 compactions, no write slowdown, nothing owed when the last write returns. v0.1.1's does
    not: level 0 reaches 8 files, 79 to 123 slowdowns, L0->L1 compactions of 4, 4, 5, 5, 6 and 6 files, 36 to 39
    compactions by the time the last write returns, and 12 or 13 still owed (0.65 to 0.71 s of work, 111 to 120 MB
    written).
  - The figures were taken at the wrong moment. Once the owed work is done both builds have made 50 compactions; the
    write amplification of overwrite is 7.02 to 7.08 in v0.1.1 and 7.39 in E.
  - The first-pass reads ran on different trees: 0/4/49/8 for v0.1.1 once its owed work was done, 3/5/50/8 for E, E+F and
    0.1.2, whose 3 level-0 tables (32 of 35 flushed tables compacted 4 at a time) nothing compacts, since shale has no
    seek compaction (ADR 0001), and every seek positions in them.
  - The engine is not at fault: E changes no compaction decision, and the policy works as written.

"""Summarizes the call graph of a macOS `sample` report, thread by thread.

Usage: sample_parse.py <report> [inclusive-name ...]

For each thread: its total samples, the functions at the top of the stack with 3% or more of them
(self samples: a node's count less its children's), and the inclusive samples of each named
function (summed over every node whose symbol contains the name, outermost occurrence only).
"""
import re
import sys
from collections import defaultdict

LINE = re.compile(r"^(?P<lead>[ +|!:]*)(?P<count>\d+) (?P<sym>.*)$")


def parse(path):
    threads = []
    in_graph = False
    with open(path, errors="replace") as f:
        for raw in f:
            line = raw.rstrip("\n")
            if line.startswith("Call graph:"):
                in_graph = True
                continue
            if not in_graph:
                continue
            if line.strip() == "" or line.startswith("Total number in stack"):
                if threads and line.startswith("Total number in stack"):
                    break
                continue
            m = LINE.match(line)
            if not m:
                continue
            depth = len(m.group("lead"))
            count = int(m.group("count"))
            sym = m.group("sym")
            if depth == 4:
                threads.append({"name": sym, "total": count, "nodes": []})
                continue
            if threads:
                threads[-1]["nodes"].append((depth, count, sym))
    return threads


def summarize(thread, names):
    nodes = thread["nodes"]
    selfs = defaultdict(int)
    inclusive = defaultdict(int)
    stack = []  # (depth, matched names)
    for i, (depth, count, sym) in enumerate(nodes):
        child_sum = 0
        # direct children: the next nodes at the smallest depth greater than this one
        j = i + 1
        child_depth = None
        while j < len(nodes) and nodes[j][0] > depth:
            if child_depth is None:
                child_depth = nodes[j][0]
            if nodes[j][0] == child_depth:
                child_sum += nodes[j][1]
            j += 1
        func = re.sub(r"\s+\(in [^)]*\).*$", "", sym).strip()
        selfs[func] += count - child_sum
        while stack and stack[-1][0] >= depth:
            stack.pop()
        enclosing = set()
        for _, matched in stack:
            enclosing |= matched
        matched_here = set()
        for n in names:
            if n in func:
                matched_here.add(n)
                if n not in enclosing:
                    inclusive[n] += count
        stack.append((depth, enclosing | matched_here))
    return selfs, inclusive


def main():
    path = sys.argv[1]
    names = sys.argv[2:]
    for t in parse(path):
        total = t["total"]
        if total == 0:
            continue
        selfs, inclusive = summarize(t, names)
        print(f"--- thread '{t['name'][:60]}': {total} samples")
        for func, c in sorted(selfs.items(), key=lambda kv: -kv[1]):
            if c * 100 < 3 * total:
                break
            print(f"    self {c:7d} {100.0 * c / total:5.1f}%  {func[:110]}")
        for n in names:
            c = inclusive.get(n, 0)
            print(f"    inclusive {c:7d} {100.0 * c / total:5.1f}%  {n}")


main()

            two = max(spreads) <= 0.02 and gap > 0.10
            print(f"  {b:8s} {row:12s} runs {[round(x) for x in meds]} max repeat spread {max(spreads) * 100:.1f}%"

#!/usr/bin/env python3
"""gen_tables.py ROOT: the Markdown tables of docs/benchmarks.md (2026-11, second session), made from the
JSON files under ROOT (the docs/benchmarks directory), with the rules of the protocol (sections 6 and 9.6)."""
import json
import statistics as st
import sys

ROOT = sys.argv[1]
READS = ["readrandom", "readmissing", "readseq", "seekrandom"]
WRITES = ["fillseq", "fillrandom", "overwrite"]
STEPS = ["v011", "e", "ef", "final"]


def load(path):
    return {r["name"]: r for r in json.load(open(path))["results"]}


def rounds(kind, build, pass_, row, key="ops_per_sec"):
    if kind == "reads":
        ps = [f"{ROOT}/2026-11-m2-reads/{build}-{pass_}-{r}.json" for r in (1, 2, 3)]
    elif kind == "writes":
        ps = [f"{ROOT}/2026-11-m2-writes/{build}-{r}.json" for r in (1, 2, 3)]
    else:
        ps = [f"{ROOT}/2026-11-m2-diagnostic/{build}-{pass_}-{r}.json" for r in (1, 2, 3)]
    return [load(p)[row][key] for p in ps]


def cell(mid, lo, hi):
    return f"{mid:,.0f} ({lo:,.0f} to {hi:,.0f})"


def rcell(v):
    return cell(st.median(v), min(v), max(v))


def interleave(a, b):
    return not (min(a) > max(b) or min(b) > max(a))


def moved_text(new, old):
    sep = min(new) > max(old) or max(new) < min(old)
    size = st.median(new) / st.median(old) - 1
    if sep and abs(size) >= 0.03:
        return f"moved ({'faster' if size > 0 else 'slower'} by {abs(size) * 100:.1f}%)"
    return f"not distinguishable from run-to-run variation ({round(size * 100, 1) + 0:+.1f}%)"


def level_text(a, b):
    ratio = st.median(a) / st.median(b)
    if interleave(a, b):
        if 0.95 <= ratio <= 1.05:
            return f"{ratio:.2f}; level with (the rounds interleave, and the ratio is within 0.95 to 1.05)"
        return f"{ratio:.2f}; the rounds interleave, and the ratio is outside 0.95 to 1.05"
    above = min(a) > max(b)
    return f"{ratio:.2f}; the rounds do not interleave (all three of 0.1.2's {'above' if above else 'below'} LevelDB's)"


HEAD = ("| benchmark | v0.1.1 ops/s | 0.1.2 ops/s | LevelDB ops/s | 0.1.2 / v0.1.1 | 0.1.2 / LevelDB |\n"
        "| --- | ---: | ---: | ---: | ---: | ---: |")

        for key, label in (("ops_per_sec", row), ("settled_ops_per_sec", f"{row}, settled")):
            vals = {}
            for b, d in docs.items():
                runs = [x[key] for x in d[row]["runs"]]
                vals[b] = (d[row][key], min(runs), max(runs))
            print(f"| {label} | {cell(*vals['v011'])} | {cell(*vals['final'])} | {cell(*vals['leveldb'])} "
                  f"| {vals['final'][0] / vals['v011'][0]:.2f} | {vals['final'][0] / vals['leveldb'][0]:.2f} |")
    print()

def steps_table(kind, pass_, rows, key="ops_per_sec", label=""):

        for a, b in zip(STEPS, STEPS[1:]):

        print(f"| {row}{label} | " + " | ".join(f"{st.median(d[b]):,.0f}" for b in STEPS) + " | "
              + " | ".join(steps) + " |")
    print()

            f, l = rounds("diag", "final", pass_, row), rounds("diag", "leveldb", pass_, row)
            print(f"<!-- {pass_} {row}: {level_text(f, l)} -->")

#!/usr/bin/env python3
"""wrappers.py PROBE_DIR: for each profile of the session, the share of the calling thread's samples whose function at
the top of the stack belongs to v0.1.1's per-table and per-block wrappers (NamedTableIterator, BoundedBlockIterator),
and to TwoLevelIterator. Uses sample_parse.py from PROBE_DIR."""
import importlib.util
import re
import sys

probe = sys.argv[1]
spec = importlib.util.spec_from_file_location("sp", f"{probe}/sample_parse.py")
sp = importlib.util.module_from_spec(spec)
saved, sys.argv = sys.argv, [sys.argv[0], "/dev/null"]
spec.loader.exec_module(sp)
sys.argv = saved
for state in ("first", "compacted"):
    for bench in ("readrandom", "readseq", "seekrandom"):
        for build in ("v011", "final"):
            threads = sp.parse(f"{probe}/prof-prof-{build}-{state}-{bench}.sample.txt")
            main = next(t for t in threads if "main-thread" in t["name"])
            selfs, _ = sp.summarize(main, [])
            total = main["total"]
            wrap = sum(c for f, c in selfs.items() if re.search(r"NamedTableIterator|BoundedBlockIterator", f))
            two = sum(c for f, c in selfs.items() if re.search(r"TwoLevelIterator", f))
            print(f"  {state:9s} {bench:10s} {build:5s} {total:5d} samples; NamedTableIterator and BoundedBlockIterator"
                  f" {100 * wrap / total:4.1f}%; TwoLevelIterator {100 * two / total:4.1f}%")
