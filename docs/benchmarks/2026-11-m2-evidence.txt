Evidence behind the explanations in docs/benchmarks.md, 2026-11
===============================================================

This file holds what was recorded in the session of 2026-11-22 that measured the read path of 0.1.2 against v0.1.1 and
LevelDB: the machine, every run with its load, wait and exit status, the system calls and the engine's counters around each
read benchmark, where the time of the calling thread went, the allocation counts, and the sources of what made the runs.
The tables of docs/benchmarks.md are made from the JSON files next to this one, under the protocol
docs/benchmarks/2026-11-m2-protocol.md, which was committed before the first run. What is here comes from the same
session (the probe runs) or from the change that made the counts (section 3). The probe is that of 2026-10
(docs/benchmarks/2026-10-m2-evidence.txt, sections 6 and 7.5), compiled with `c++ -O2 -g -std=c++20` against each build's
Release libraries; its speeds are not quoted, only its counts and shares. `$WORK` is the scratch directory of the session,
`$DB` the empty database directory. Paths in this file are written with those names.

The session differs from the one of 2026-10 in the operating system (macOS 27.2.1, then 26.6.2), libc++ (2200.27.0, then
2000.63.0) and libSystem (1359, then 1356); section 0 has the record.

2. Where the time of the calling thread went (probe, sampled with `sample`)
------------------------------------------------------------

`MARK loop <benchmark>`, and ran `sample <pid> 4` on it; `sample_parse.py` and `categories.py` classified the samples of the
thread that calls the engine. The loops are 3 for `readrandom`, 40 for `readseq` and 2 for `seekrandom`, so that the 4
seconds fall inside the timed loop. The command line of each run is in section 0. The share is of the samples of that thread
in that run, by the function at the top of the stack, and is not a time. The profile of LevelDB was not taken again.

--- measure.sh ---
#!/usr/bin/env bash
# measure.sh <label> <argument>...
# Waits for the machine to be quiet, then runs one command under caffeinate and appends the record of
# the run to $EVIDENCE. $BENCH is the command (shale_bench, or a probe), $DB the database directory (made
# empty before the run), $WORK the scratch directory. Paths under $WORK and $DB are written to the
# record as $WORK and $DB. Standard output and standard error are kept in $WORK/logs (never in the
# repository), and a non-empty standard error is named in the record. Exit status: the run's, or 3 if the machine was not
# quiet within two hours of wall time.
set -uo pipefail
: "${BENCH:?}" "${DB:?}" "${EVIDENCE:?}" "${WORK:?}"
label=$1; shift
names='^(ninja|clang|clang\+\+|clang-.*|cmake|ctest|ld|ld64|shale_.*|fuzz_.*)$'
busy='process named ninja, clang, cmake, ctest, ld, ld64, shale_* or fuzz_*'
limit=7200 poll=15 begin=$(date +%s)
while :; do
  load=$(sysctl -n vm.loadavg | tr -d '{}' | awk '{print $1}')
  procs=$(ps -axo comm= | awk -F/ '{print $NF}' | grep -E "$names" || true)
  power=$(pmset -g batt | head -1)
  waited=$(($(date +%s) - begin))
  if awk -v l="$load" 'BEGIN{exit !(l < 2.0)}' && [ -z "$procs" ] && [[ "$power" == *"AC Power"* ]]; then break; fi
  if [ "$waited" -ge "$limit" ]; then
    echo "$label: not quiet after $waited s: load $load, processes '${procs//$'\n'/ }', $power" | tee -a "$EVIDENCE" >&2
    exit 3
  fi
  caffeinate -ims sleep "$poll"
done
base="$WORK/logs/${label//[^A-Za-z0-9._-]/_}"
errfile="$base.stderr" outfile="$base.stdout"
for a in "$@"; do case "$a" in --json=*) mkdir -p "$(dirname "${a#--json=}")";; esac; done
mkdir -p "$WORK/logs"
shown() { local s=$*; s=${s//"$DB"/\$DB}; s=${s//"$WORK"/\$WORK}; echo "$s"; }
rm -rf "$DB"; mkdir -p "$DB"
{
  echo "$label"
  echo "  quiet: load average (1 min) $load, no $busy, waited $waited s"
  echo "  start: $(date '+%Y-%m-%d %H:%M:%S %z')"
  echo "  uptime at start: $(uptime)"
  echo "  power at start: $power"
  echo "  command: $(shown "caffeinate -ims $BENCH $*")"
  echo "  standard output kept in: $(shown "$outfile")"
} >> "$EVIDENCE"
caffeinate -ims "$BENCH" "$@" > "$outfile.run" 2> "$errfile.run"
status=$?
{
  echo "  exit status: $status"
  if [ -s "$errfile.run" ]; then
    echo "  standard error kept in: $(shown "$errfile")"
    echo "  last line of standard error: $(shown "$(tail -n 1 "$errfile.run")")"
  fi
  echo "  end: $(date '+%Y-%m-%d %H:%M:%S %z')"
  echo "  uptime at end: $(uptime)"
  echo
} >> "$EVIDENCE"
cat "$outfile.run" >> "$outfile"; cat "$outfile.run"
if [ -s "$errfile.run" ]; then cat "$errfile.run" >> "$errfile"; cat "$errfile.run" >&2; fi
rm -f "$errfile.run" "$outfile.run"
exit "$status"

--- table.py ---
#!/usr/bin/env python3
"""table.py FILE... : Markdown rows from shale_bench JSON files.

One file: each benchmark's median ops/s, with the lowest and highest of its runs in brackets (the main
table). Several files (the rounds of one build and pass): the median of the files' medians, with the
lowest and highest file in brackets (the figure to quote), and p99 the same way.
"""
import json
import statistics
import sys


def main(paths):
    docs = [json.load(open(p)) for p in paths]
    names = [r["name"] for r in docs[0]["results"]]
    print("| benchmark | ops/s | p99 (us) |")
    print("| --- | --- | --- |")
    for name in names:
        rows = [next(r for r in d["results"] if r["name"] == name) for d in docs]
        if len(docs) == 1:
            ops = [run["ops_per_sec"] for run in rows[0]["runs"]]
            p99 = [run["p99_us"] for run in rows[0]["runs"]]
            mid_ops, mid_p99 = rows[0]["ops_per_sec"], rows[0]["p99_us"]
        else:
            ops = [r["ops_per_sec"] for r in rows]
            p99 = [r["p99_us"] for r in rows]
            mid_ops = statistics.median(ops)
            mid_p99 = statistics.median(p99) if None not in p99 else None
        cell = "n/a"
        if None not in p99:
            cell = f"{mid_p99:,.1f} [{min(p99):,.1f}, {max(p99):,.1f}]"
        print(f"| {name} | {mid_ops:,.0f} [{min(ops):,.0f}, {max(ops):,.0f}] | {cell} |")


if __name__ == "__main__":
    main(sys.argv[1:])

4.2 driver.sh: ran blocks A, B, W, C and D of the protocol in order, each run through measure.sh, a failed run once more and
a second failure or a timeout stopping it. It ends by writing a marker file. (The scratch directory is written $WORK here.)

--- driver.sh ---
#!/usr/bin/env bash
# Runs protocol sections 4 A, B, W, C and D in order, each run through measure.sh.
# Run from the root of the repository checkout. Always ends: it writes $WORK/driver.done on exit.
set -uo pipefail
export WORK=$WORK DB=$WORK/db
export EVIDENCE=${EVIDENCE:-$WORK/evidence-runs.txt} SCRATCH=$WORK/probe
MEASURE=${MEASURE:-$WORK/measure.sh} NUM=${NUM:-1000000}
log=$WORK/driver.log
rm -f $WORK/driver.done
trap 'echo "$(date +%H:%M:%S) driver exit" >> $log; touch $WORK/driver.done' EXIT
say() { echo "$(date +%H:%M:%S) $*" >> $log; }
ALL="v011 e ef final leveldb"
order() { case $1 in 1) echo "v011 e ef final leveldb";; 2) echo "leveldb final ef e v011";; 3) echo "ef v011 leveldb e final";; esac; }
bin() { echo "$WORK/$([ "$1" = leveldb ] && echo final || echo "$1")/build/tools/shale_bench"; }
eng() { [ "$1" = leveldb ] && echo --engine=leveldb || echo --engine=shale; }
# run <label> <build> <args...>: one run; a failure is run again once; a second failure or a timeout stops.
run() {
  local label=$1 build=$2; shift 2
  for attempt in 1 2; do
    say "start $label (attempt $attempt)"
    local l=$label; [ $attempt = 2 ] && l="$label (rerun)"
    BENCH=$(bin "$build") bash $MEASURE "$l" "$@"; local rc=$?
    say "end $label rc=$rc"
    [ $rc = 0 ] && return 0
    [ $rc = 3 ] && { say "STOP: quiet check timed out"; exit 3; }
  done
  say "STOP: $label failed twice"; exit 1
}
R=${R:-docs/benchmarks}
FULL=fillseq,fillrandom,fillsync,overwrite,readrandom,readmissing,readseq,seekrandom
RD=overwrite,readrandom,readmissing,readseq,seekrandom
say "A first pass"
[ -n "${SKIP_AB:-}" ] || for b in $ALL; do run "A first $b" $b $(eng $b) --benchmarks=$FULL --num=$NUM --repeat=3 --db=$DB --json=$R/2026-11-m2-$b.json; done
say "A compacted pass"
[ -n "${SKIP_AB:-}" ] || for b in $ALL; do run "A compacted $b" $b $(eng $b) --benchmarks=$FULL --num=$NUM --repeat=3 --db=$DB --json=$R/2026-11-m2-$b-compacted.json --compact_before_reads; done
say "B"
for r in $([ -n "${SKIP_AB:-}" ] || echo 1 2 3); do
  for b in $(order $r); do run "B first r$r $b" $b $(eng $b) --benchmarks=$RD --num=$NUM --repeat=3 --db=$DB --json=$R/2026-11-m2-reads/$b-first-$r.json; done
  for b in $(order $r); do run "B compacted r$r $b" $b $(eng $b) --benchmarks=$RD --num=$NUM --repeat=3 --db=$DB --json=$R/2026-11-m2-reads/$b-compacted-$r.json --compact_before_reads; done
done
say "W"
for r in 1 2 3; do
  for b in $(order $r); do run "W r$r $b" $b $(eng $b) --benchmarks=fillseq,fillrandom,overwrite --num=$NUM --repeat=3 --db=$DB --json=$R/2026-11-m2-writes/$b-$r.json; done
done
say "C"
for r in 1 2 3; do
  if [ $r = 2 ]; then co="leveldb final"; else co="final leveldb"; fi
  for pass in first compacted; do
    for b in $co; do
      extra=(); [ $pass = compacted ] && extra=(--compact_before_reads)
      cs=(); [ $b = final ] && cs=(--cache_size=1073741824)
      run "C $pass r$r $b" $b $(eng $b) ${cs[@]+"${cs[@]}"} --benchmarks=$RD --num=$NUM --repeat=3 --db=$DB --json=$R/2026-11-m2-diagnostic/$b-$pass-$r.json ${extra[@]+"${extra[@]}"}
    done
  done
done
say "D"
probe() { # probe <build> <label> <args to profile.sh after the probe path>
  local build=$1 label=$2; shift 2
  for attempt in 1 2; do
    local l=$label; [ $attempt = 2 ] && l="$label (rerun)"
    say "start probe $label (attempt $attempt)"
    BENCH=$WORK/probe/profile.sh bash $MEASURE "$l" "$WORK/probe/probe-$build" "$label" "$@"; local rc=$?
    local san=${l//[^A-Za-z0-9._-]/_}
    if [ $rc = 3 ]; then say "STOP: quiet check timed out"; exit 3; fi
    if [ $rc = 0 ] && grep -q "^$label: probe exit 0" "$WORK/logs/$san.stdout" && grep -q '^interpose:' "$SCRATCH/prof-$label.out"; then say "end probe $label ok"; return 0; fi
    say "end probe $label FAILED (rc=$rc)"
  done
  say "STOP: probe $label failed twice"; exit 1
}
for b in v011 final; do
  for state in first compacted; do
    c=""; [ $state = compacted ] && c=1
    probe $b "count-$b-$state" $NUM fillrandom,overwrite,readrandom,readmissing,readseq,seekrandom 1 1 1 $c
  done
  for state in first compacted; do
    c=""; [ $state = compacted ] && c=1
    for bench in readrandom:3 readseq:40 seekrandom:2; do
      n=${bench%%:*}; loops=${bench##*:}
      probe $b "prof-$b-$state-$n" $NUM fillrandom,overwrite,$n "MARK loop $n" 4 $loops $c
    done
  done
done
say "ALL DONE"

#!/usr/bin/env python3
"""analyze.py ROOT: applies the reporting rules of the 2026-11 protocol (section 6) to the result files.

ROOT is the docs/benchmarks directory. Prints, for every row: the medians, the ratios, and the answer
of each rule. Reads ops/s only.
"""
import json
import statistics as st
import sys

ROOT = sys.argv[1]
BUILDS = ["v011", "e", "ef", "final", "leveldb"]
ORDER = ["v011", "e", "ef", "final"]
READS = ["readrandom", "readmissing", "readseq", "seekrandom"]
WRITES = ["fillseq", "fillrandom", "overwrite"]


def load(path):
    return {r["name"]: r for r in json.load(open(path))["results"]}


def ops(path, row):
    return load(path)[row]["ops_per_sec"]


def rounds(kind, build, pass_, row):
    if kind == "reads":
        return [ops(f"{ROOT}/2026-11-m2-reads/{build}-{pass_}-{r}.json", row) for r in (1, 2, 3)]
    if kind == "writes":
        return [ops(f"{ROOT}/2026-11-m2-writes/{build}-{r}.json", row) for r in (1, 2, 3)]
    if kind == "diag":
        return [ops(f"{ROOT}/2026-11-m2-diagnostic/{build}-{pass_}-{r}.json", row) for r in (1, 2, 3)]


def interleave(a, b):
    return not (min(a) > max(b) or min(b) > max(a))


def moved(new, old):
    sep = min(new) > max(old) or max(new) < min(old)
    size = st.median(new) / st.median(old) - 1
    return sep and abs(size) >= 0.03, sep, size


def fmt(v):
    return f"{st.median(v):,.0f} [{min(v):,.0f}, {max(v):,.0f}]"


def table(kind, rows, passes):
    for pass_ in passes:
        print(f"\n## {kind} {pass_}")
        for row in rows:
            data = {b: rounds(kind, b, pass_, row) for b in BUILDS}
            print(f"\n{row}")
            for b in BUILDS:
                print(f"  {b:8s} {fmt(data[b])}   rounds {[round(x) for x in data[b]]}")
            f, l, v = data["final"], data["leveldb"], data["v011"]
            print(f"  final/v011 {st.median(f)/st.median(v):.3f}  moved={moved(f, v)}")
            print(f"  final/leveldb {st.median(f)/st.median(l):.3f}  interleave={interleave(f, l)}"
                  f"  level_with={interleave(f, l) and 0.95 <= st.median(f)/st.median(l) <= 1.05}")
            print(f"  v011/leveldb {st.median(v)/st.median(l):.3f}  interleave={interleave(v, l)}"
                  f"  level_with={interleave(v, l) and 0.95 <= st.median(v)/st.median(l) <= 1.05}")
            for a, b in zip(ORDER, ORDER[1:]):
                m = moved(data[b], data[a])
                print(f"  step {a}->{b}: ratio {st.median(data[b])/st.median(data[a]):.3f} moved={m[0]} separated={m[1]}")


def main_table():
    for suffix in ("", "-compacted"):
        print(f"\n## A{suffix or ' first'}")
        names = list(load(f"{ROOT}/2026-11-m2-final{suffix}.json"))
        for row in names:
            vals = {}
            for b in BUILDS:
                r = load(f"{ROOT}/2026-11-m2-{b}{suffix}.json")[row]
                vals[b] = (r["ops_per_sec"], min(x["ops_per_sec"] for x in r["runs"]), max(x["ops_per_sec"] for x in r["runs"]))
            line = "  ".join(f"{b} {vals[b][0]:,.0f} [{vals[b][1]:,.0f}, {vals[b][2]:,.0f}]" for b in BUILDS)
            print(f"{row:12s} {line}  final/v011 {vals['final'][0]/vals['v011'][0]:.3f} final/leveldb {vals['final'][0]/vals['leveldb'][0]:.3f}")


def levels():
    print("\n## two levels (first pass: the run of A and the three rounds of B)")
    for b in BUILDS:
        for row in READS:
            meds, spreads = [], []
            paths = [f"{ROOT}/2026-11-m2-{b}.json"] + [f"{ROOT}/2026-11-m2-reads/{b}-first-{r}.json" for r in (1, 2, 3)]
            for p in paths:
                r = load(p)[row]
                meds.append(r["ops_per_sec"])
                o = [x["ops_per_sec"] for x in r["runs"]]
                spreads.append(max(o) / min(o) - 1)
            s = sorted(meds)
            gap = max((s[i + 1] / s[i] - 1, i) for i in range(len(s) - 1))
            two = max(spreads) <= 0.02 and gap[0] > 0.10
            print(f"  {b:8s} {row:12s} runs {[round(x) for x in meds]} max repeat spread {max(spreads)*100:.1f}% biggest gap {gap[0]*100:.1f}% two_levels={two}")


main_table()
table("reads", READS, ["first", "compacted"])
table("writes", WRITES, [None])
print("\n## diagnostic (C): final with 1 GiB cache against leveldb as configured, and against final's own rounds in B")
for pass_ in ("first", "compacted"):
    for row in ["readrandom", "seekrandom"]:
        f, l = rounds("diag", "final", pass_, row), rounds("diag", "leveldb", pass_, row)
        fb = rounds("reads", "final", pass_, row)
        print(f"{pass_} {row}: final+1GiB {fmt(f)} leveldb {fmt(l)} ratio {st.median(f)/st.median(l):.3f} interleave={interleave(f, l)} | final 8MiB (B) {fmt(fb)} cache gain {st.median(f)/st.median(fb):.3f}")
levels()

4.4 The probe. probe.cc, interpose.c, profile.sh and sample_parse.py are the texts of sections 6 and 7.5 of
docs/benchmarks/2026-10-m2-evidence.txt, extracted by line range and unchanged (an empty diff). categories.py is the same text
except that the line `"sp", "$SCRATCH/sample_parse.py")` has `$SCRATCH` replaced by the path of the probe directory, as the
text of 2026-10 says to ($SCRATCH is the scratch directory the probe was built in):

  7c7
  <     "sp", "$SCRATCH/sample_parse.py")
  ---
  >     "sp", "$WORK/probe/sample_parse.py")

The probes were built with the one command below for each build (`<n>` is v011, e, ef or final; the same command, differing
only in the build directory), and interpose.dylib with `cc -dynamiclib -O2 -o interpose.dylib interpose.c`:

--- build-probe.sh ---
#!/usr/bin/env bash
# build-probe.sh <name>: the one compile command for both probes.
set -euo pipefail
n=$1; B=$WORK/$n/build
c++ -O2 -g -std=c++20 -I"$WORK/$n/include" -I"$WORK/$n/tools" -I"$(brew --prefix leveldb)/include" \
  "$WORK/probe/probe.cc" -o "$WORK/probe/probe-$n" \
  "$B/tools/libshale_bench_support.a" "$B/tools/libshale_bench_leveldb.a" \
  "$B/src/libshale_db.a" "$B/src/libshale_io.a" "$B/src/libshale_core.a" "$B/src/libshale_util.a" \
  -L"$(brew --prefix leveldb)/lib" -lleveldb

Every profile.sh invocation is the command line in section 0 (`$WORK/probe/profile.sh <probe> <label> <keys> <benchmarks>
<mark-or-delay> <seconds> <loops> [compact]`, run through measure.sh, with SCRATCH=$WORK/probe set in the environment). A
probe run counted as a success only if the standard output had `<label>: probe exit 0` and the probe's own output file had the
`interpose:` lines, as the protocol says; all 20 did.
